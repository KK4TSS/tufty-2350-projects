#Tufty 2350 Projects
A home for my projects, experiments, artwork, and setup notes for the Pimoroni Tufty 2350.

I’m keeping these projects together so they’re easy to find, follow, and build on. Expect small apps, playful ideas, and useful things for the badge.

## What I'm working on

### Halloween

A glowing pumpkin, floating ghosts, and a BOO button. A little Halloween fun for the Tufty.

Halloween is already up in badgeware-contrib. You can get the app and instructions [here](https://github.com/pimoroni/badgeware-contrib/tree/main/Tufty/halloween).

### Wait Time Sign

A theme park wait-time app with a wait board, favorites, and illustrated park views.

Wait-time data comes from [Queue-Times.com](https://queue-times.com/).

## Getting started
These projects target the Tufty 2350. Check each app’s README for its firmware requirements and installation instructions; they are not intended for the Tufty 2040.

For Badgeware apps, installation generally means copying the complete app folder into the device’s apps folder, safely ejecting the device, and returning to the launcher. Always follow the individual project’s instructions.

Keep Wi-Fi passwords, API keys, and personal device configuration out of the public repository.

## Putting an app on your Tufty

These are for the Tufty 2350 running Badgeware. Check the README in each project's folder for what it needs and how to install it.

Most apps go into the `apps` folder on the Tufty. Copy the whole project folder, safely eject, and follow that app's instructions.
